# 《增长黑客》第8章 阅读笔记 —— 完整案例集

## 本章一句话

> 今天的粗糙执行，好过明天的完美计划。
> 五家公司从零做大的全过程，把前七章的招数挨个演了一遍。

这是全书最后一章正文，也是一场"大汇演"：Airbnb、Tinder、Github、美丽说、外卖库，五个完整案例，正好把 AARRR 各环节的方法串起来看。读的时候建议对照前面章节，看每个公司用了哪几招。

## 一、Airbnb：从卖麦片到估值 200 亿（8.1）

两个付不起房租的设计师，把三张气垫床摆进客厅，做起了"家庭旅店"网站。七年后，它的夜间订房量超过希尔顿，估值约 200 亿美元。

它一路用过的增长招数，几乎每章都能对上号：

| 招数 | 具体做法 | 对应章节 |
|------|---------|---------|
| 绝境求生 | 没钱就卖"奥巴马款/麦凯恩款"选举主题麦片，挣了 3 万美元，还打动了投资人保罗·格雷厄姆："能靠卖麦片挣钱的人，项目死不了" | 前传 |
| 蹭大平台流量 | 写机器人帮用户把房源一键同步发布到竞争对手 Craigslist（对方没接口，靠解析网址硬做），把对方用户挖过来 | 第3章借鸡下蛋 |
| 借邮件系统 | 模拟成客户给 Craigslist 房东"留言"推荐自己，借对方的邮件系统打广告，零成本 | 第7章借势 |
| 上门拍照 | 发现房子卖不动是因为照片太丑，租高档相机挨家挨户免费拍，纽约订房量涨两三倍，月收入翻倍 | 第3章笨办法 |
| 社交信任 | 连接 Facebook，能看到房东和自己的共同好友，解决陌生人住进家里的信任难题 | 第4章社交维系 |
| 星改心 | 心愿单图标从星形改成心形，使用率涨 30% | 第4章 A/B 测试 |
| 推荐计划 | 文案写"送好友 25 美元旅行经费"比"邀请好友你得 25 美元"更打动人（利他比利己好），某些地区订单涨 25% | 第7章人性开关 |
| 拥抱移动 | 移动用户响应需求快 3 倍、成交率高 8 倍 | 趋势 |

> 说句大白话：Airbnb 没有什么一招制胜，就是把每一步能想到的小事都做扎实：照片丑就上门拍，信任难就挂上共同好友，连一个图标都拿来测试。

## 二、Tinder：左滑右滑的看脸社交（8.2）

> 说句大白话：看照片，顺眼往右滑，不顺眼往左滑。两个人都往右滑，就能开聊。就这么简单。

哈佛的研究说人 3 岁起就以貌取人，Tinder 干脆把这一条做成了产品的全部。上线两个月匹配超 100 万对，后来 5000 万用户每天平均用 90 分钟。

它的增长拆解：

- **得女性者得天下**：约会产品冷启动的老大难。Tinder 先攻下洛杉矶派对圈最受欢迎的 600 人（社交影响力节点），再让推广负责人飞遍全国高校，先拉女生联谊会、再拉兄弟会。男生打开一看周围女生都在，动力就来了。跟酒吧"男 A 女免"一个道理。
- **产品机制设计**：一只手就能滑，零学习成本；永远不知道下一个是谁，随机性让人停不下来；"看脸"默认成了游戏规则，女生只跟自己看着顺眼的人聊，不受骚扰，这是口碑点。
- **Facebook 登录**：不用填一堆资料，还继承了真实身份，没人能披马甲，环境更可信。
- **牵红线功能**：让用户拉两位陌生朋友发起群聊，红娘们有了舞台，害羞的人也有了"只是被朋友拉进来看看"的借口。
- **安卓征服世界**：美国 iPhone 用户见顶后转向安卓和国际市场，在难啃的土耳其请社交名媛和奥运选手站台，增长立刻起飞。
- **付费探索**：Tinder Plus 按年龄差异化收费（年轻用户手头紧就便宜点），付费能"反悔左滑"、漫游到其他国家看人。

## 三、Github：把协作做成网络效应（8.3）

程序员的代码托管社区。2008 年以"周末项目"起家，2012 年估值 7.5 亿美元。第 100 万个代码仓库用了近 4 年，从 900 万到 1000 万只用了 48 天。

增长拆解：

- **解决真实痛点**：在它之前，协作写代码要下载代码包、打补丁、发邮件、原作者手工核对。Github 用复制（Fork）、拉拽请求（Pull Request）、合并（Merge）把这一套简化到极致。
- **网络效应**：用的人越多，代码越多，社区对所有人价值越大，"用的人越多就越好用"。高手云集之后，猎头干脆拿 Github 主页当简历看，大家更卖力经营。
- **免费带动收费**：公开仓库免费，私密仓库收费，企业级服务另算。向愿意掏钱的人收到了钱，免费用户也没觉得被冒犯。
- **金牌项目入驻**：Twitter 等巨头把开源项目放上来，网友来看顶级公司怎么写代码，社区地位水涨船高。
- **尽早交付**：先上线再看用户怎么用，不追求完美才发布。这跟精益创业一脉相承。

## 四、美丽说：粉色社区的冷启动（8.4）

女性时尚分享社区，从五道口的出租屋起步，做到 1 亿注册用户。

这一段最有参考价值的是冷启动的笨功夫和社区分层运营：

- **500 元的种子用户**：最初潜进 QQ 群发链接，秒被踢。后来每月付群主 500 元，请她们带人进来玩，慢慢养出两个百人小组。到年底日 IP 冲到 7 万。
- **拒绝男人**：主色调定为蔷薇粉，男性可以浏览但禁止注册，作者试着用微博注册也被系统识破拦下。理由很简单：女性社区的氛围容不得"求交往"式搅局（第3章"产品蝗虫"的实操版）。
- **用户分四层**：时尚达人（约 300 人，付费签约，负责好看）、超级用户（约 5%，懂时尚爱表达，负责内容）、活跃用户（爱传播）、需求群众（最多，找货下单就走）。前两层是发动机，喂饱她们，后面两层自然有的看。
- **更聪明的分享链接**：分享网址自动抓取商品图和标题，别人不用点进去就知道是什么。以前发链接像"给你看美女照片却不给联系方式"。
- **小测试滚雪球**：高峰期每周做六七款微博心理测试（"测测你是甄嬛传里的谁"），结果要先分享才能看，单个测试能滚到一二十万授权用户。
- **做减法**：App 里"一起拍""找闺蜜"两个功能是团队臆想出来的需求，商场旁边摆大头贴机，成不了社区，两个月后果断砍掉。
- **流量生意**：三阶段路径，先聚社区、再做导购目录（低价买流量、高价卖流量）、最后围绕人群深挖生态。徐易容的说法：创业要有梦想而不是理想，梦想由心决定，理想由大脑决定、容易压垮自己。

## 五、外卖库：0 到 100 万的实战手册（8.5）

> 说句大白话：这是全书最"手把手"的一章，联合创始人亲述，没钱没资源时每一步怎么抠。

几个最值得抄的做法：

- **SEO 起家**：研究发现用户常搜"地点＋外卖电话""餐馆名＋外卖"，就围绕这些词做优化；上线半年，搜索流量占比从 20% 提到 60%，"北京外卖"从第四页进到第一页。三年后每天还能白来 5000 个访问。SEO 心法：伺候好用户，再伺候好搜索引擎。
- **求助探测器**：写程序监控微博和百度知道上的求助（"跪求五道口外卖电话"），再以"喂人民服务小分队"名义人工认真回复。技术负责发现，人负责真诚。
- **陈奕迅字幕组**：把香港麦当劳"陈奕迅送外卖"的粤语视频做成中字版传上优酷，片尾贴 3 秒自家广告，微博转发 8000 多次，播放几十万。成本几乎为零，蹭的是明星和品牌的热。
- **兔子外卖袋**：给外卖店免费送设计成兔子脸的塑料袋（打结后把手变兔耳朵），配上"呐，吃外卖呢，最重要是开心"的 TVB 体文案。随手发微博，假期结束转发过 2 万，还有人私信要买。方便别人就是成全自己。
- **试吃卧底**：5000 元预算招高校"吃货卧底"试吃发报告，礼品袋里放一枚"股份"，最后没人卷款跑路，换来 50 篇报告。
- **外卖星探**：用户拍菜单上传，给 2 元奖金或捐给"免费午餐"公益（3 元一份贫困学生午餐）。一个小小的捐赠按钮，让信息量从 6000 家店暴增到 190 个地区 3 万多家。
- **App Store 冲榜**：上线前把标题、关键词、图标、截图全按规则优化；提前一周私信 iPhone 粉丝打招呼，上线当天群发下载链接；给外卖店老板发短信。第一天冲到生活榜第 22 名。

创始人赵珏映的总结很动人：一路走来并不优雅，但只要不放弃任何可能，一句指点、一个搞笑视频、一点人品、一个小想法，都可能成为翻过障碍的关键。

## 💡 个人启发要点

- 这一章最好的读法是"对答案"：把每个案例拆开，会发现全是前七章学过的招。Airbnb 上门拍照是笨办法，Tinder 校园地推是种子用户，Github 私库收费是免费增值，美丽说小测试是体外病毒循环，外卖库 SEO 是搜索引擎优化。方法就那些，差别在于执行得多狠。
- Airbnb 的故事给我最大的触动是"求生欲"：卖麦片这种事看起来不体面，但正是这种"什么都能试"的劲头让投资人信了他们。早期团队最值钱的不是面子，是活下来的能力。
- Tinder 和美丽说共同印证了第3章那句话：得女性者得天下。两家都先精心服务女性用户，男性用户和氛围自然跟着来。反过来的产品大多做成了"蝗虫灾区"。
- Github 是"用的人越多越好用"的教科书。做平台类产品，网络效应就是护城河，前期宁可慢一点养生态，也别急着一手交钱一手交货。
- 外卖库证明"穷"不是借口。零预算也能撬动增长：SEO、蹭热点、兔袋子、公益按钮，每个都不花什么钱，但都需要极度用心。它家两个细节我记住了：技术上能群发也要人工认真回复，以及给外卖店送袋子的"方便别人就是成全自己"。
- 全书到这就读完了。回头看，增长黑客的全部秘密其实就一句话：用数据代替猜、用试验代替吵、用巧劲代替砸钱，然后在正确的产品上，把 AARRR 每一环都磨到发光。
