## 这一笔记说明

全书正文八章读完，还剩三个"尾巴"：后记讲职业道德，附录 A 是指标词典，附录 B 是人物名单。合并成一篇收尾。

## 一、后记：增长黑客的职业道德

> 说句大白话：增长的手段有千百种，但有些钱不能赚，有些事不能干。技术是中立的，用技术的人得有底线。

开篇是个反面教材。2014 年游戏"疯狂来往"把玩家游戏时拍的视频（有人衣着随意甚至赤膊），未经任何授权传到了公开的优酷账号上，酿成全民"艳照门"。优酷紧急删了 3.6 万条视频，但视频平均已被播放数十万次。作者判断这多半不是失误：这家公司做过爆红的"疯狂猜图"，不可能不懂病毒传播，半年不清理违规视频更说不过去。负面围观带来了流量，可这种踩着用户隐私换来的增长，输掉的是信任。

类似的越界并不少见：Path 偷偷上传用户通讯录、SkillPages 拿到 Gmail 授权就向全体联系人群发广告、有 App 在后台静默下载别的程序。这些招数看着"聪明"，实则是拿用户当猴耍。连作者走访过的增长黑客自己都承认："有些案例可以公开聊，有些只能私下说，端不上台面。"能自知，说明大家心里其实有杆秤。

周鸿祎的例子是个注脚：早年靠 3721 拿下大半个中国网民，也背上了"流氓软件之父"的骂名，最后靠 360 安全卫士"手刃"昔日产品完成自我救赎。能自我反省的团队，市面上并不多。

作者给出三条实践准则：

1. **换位思考**：己所不欲，勿施于人。站在用户角度想想，很多决定用常识就能判断，不需要多高明的理论。
2. **隐私保护**：用户没有义务懂技术，却要承担技术滥用的后果。开发者应"能力越大责任越大"，只征求最小授权，给最大知情。
3. **国际视野**：国外对越界行为的界定和惩罚更明确。想做世界级公司，从第一天就该守住契约精神，做"百年老店"，别被快钱蒙了眼。

作者最后一句挺真诚：唯愿这本书披露的案例和思路，别把涉世未深的新手带进沟里。

## 二、附录 A：增长黑客常用指标速查

> 说句大白话：这是全书的"度量衡"。前面八章反复念叨"用数据说话"，这篇就是该看哪些数。适合当工具页收藏，用时翻查。

### 网站类指标

| 指标 | 一句话解释 |
|------|-----------|
| PV（页面浏览量） | 页面被看了多少次，同一人刷 3 次算 3。像电视的收视率，但能被"刷"出来，别全信 |
| UV（独立访问者） | 多少个不同的人来过。看网站覆盖人数，但校园网、公司统一出口 IP 会让它不准 |
| Visit（访问数） | 一次进来到离开的完整过程。隔 30 分钟以上再来，算两次 |
| 着陆页 | 访客进站看到的第一个页面，是判断广告效果的地方 |
| 退出页 | 访客离开前看的最后一个页面。下单页退出率高就要查，那是流量漏洞 |
| 跳出率 | 只看一页就走的人占比。跳出率越高，问题越大 |
| 展现数 | 广告被加载出来的次数 |
| 打点数 | 服务器收到请求的次数，一个 10 图的页面算 11 次 |
| 转化率 | 完成目标动作（注册、下载、下单）的人占比 |
| 停留时间 | 一次访问待了多久 |
| 初访者 / 回访者 | 头回来的客人 vs 回头客，两者相加等于 UV |
| 访问来源 | 人从哪来：搜索引擎、外站推荐、直接输入 |

### 移动应用类指标

| 指标 | 一句话解释 |
|------|-----------|
| 新增用户数 | 头一次打开 App 的人数（按设备识别） |
| 活跃用户数 | 周期内用过的人，通常看日活 DAU 和月活 MAU。"用过"怎么定义，看团队真正在乎什么 |
| 升级用户数 | 从老版本升上来的人。QQ 每天海量"下载"里很大一块是这个 |
| 留存率 | 过段时间还留着的比例。看次日、7 日、30 日。因真实需求而来留存高，因有奖活动而来留存低 |
| 总用户数 | 历史新增加总，含水分，流失的也算在内 |
| 单次使用时长 / 平均单次使用时长 | 一次打开用多久。工具类几秒，视频类几十分钟，得按品类看 |
| 使用间隔 | 两次使用隔多久。间隔太长说明没养成习惯 |
| 转化率 | App 内特定动作（点击、播放、邀请）的完成比例 |
| K 因子 | 平均一个用户带来几个新用户，大于 1 才能自我裂变 |
| ARPU | 平均从每个用户身上赚多少钱 |
| ARPPU | 只算付费用户的平均收益，看付费人群的支付力 |
| 月付费率 | 一个月里付费的人占活跃用户的比例 |
| LTV（生命周期价值） | 一个用户从第一次用到最后一次，累计贡献了多少钱 |

> 打个比方：ARPU 是"全店客人平均消费"，ARPPU 是"买单客人平均消费"，LTV 是"一位熟客一辈子在你家花多少钱"。LTV 要是高过获取一个用户的成本，这门生意就能自我造血。

## 💡 全书读完的小结

八章正文加后记附录，合上书能剩下的东西：

- 一条主线：AARRR 漏斗，获取、活跃、留存、收入、传播，五个齿轮咬着转。
- 一套方法：先验证产品对不对（PMF、MVP），再用数据代替猜（指标、A/B 测试），用巧劲代替砸钱（病毒传播、借势、Bug 营销）。
- 一个前提：增长的所有手段，都建立在用户信任之上。后记那句"有些钱不能赚"，和第一章"数据为王"一样重要。

工具会过时，案例会过时，这套思维方式和那条底线不会。
