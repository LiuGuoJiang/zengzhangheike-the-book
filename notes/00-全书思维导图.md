## 🧭 一、认识增长黑客(第1章)

- **是什么**:以数据驱动营销、以市场指导产品、用技术手段做增长的人
- **为什么需要**
  - 初创公司 75% 破产,烧不起广告费
  - 买量成本 2~3 年涨 3~5 倍
- **开山案例:Hotmail**
  - 每封邮件末尾加一句"快来申领免费邮箱"
  - 6 个月 100 万用户,零广告费
- **全书主线:AARRR 漏斗**(饭馆类比)
  - Acquisition 获取:把路人招进店
  - Activation 活跃:落座点菜用券
  - Retention 留存:变成回头客
  - Revenue 收入:提高翻台率
  - Referral 传播:顾客带朋友来
- **五大特质**
  - 数据为王 / 专注目标 / 关注细节 / 富于创意 / 信息通透
- **标杆:Andy Johns**
  - Twitter 登录页改造,24 小时注册率 +250%
- **工作循环**:头脑风暴 → 排优先级 → 测试 → 分析 → 常态化

## 🎯 二、创造正确的产品(第2章)

- **核心:先做对,再做快**;方向错了跑得越快越远
- **PMF(产品对上市场)**
  - 42% 创业失败因为"没有市场需求"
  - PMF 之前:不打广告、不过度优化
- **正面:Instagram** = Burbn 做减法,只留照片分享,551 天卖 10 亿美元
- **反面:叮咚小区** = 产品没验证就砸 1 亿推广,半年崩盘
- **需求四问**
  - 真需求还是伪需求(QQ 邮箱附件功能的教训)
  - 刚需还是弹性(查信息/买东西/与人联系 = BAT)
  - 市场够不够肥(雷军:做最肥的市场)
  - 能不能变现(搜狗三级火箭 / VeryCD 转型神仙道)
- **MVP(最小可行产品)**
  - 摆小摊试菜,再开大饭店
  - 回答两问:有没有人要(价值假设)/ 愿不愿掏钱(增长假设)
  - 案例:Dropbox 一段视频 / Groupon 手敲 WordPress / Zappos 买来再寄 / 大众点评抄菜单 / Sendwithus 假网站 28 美元
  - 微信 MVP:聚美优品砍方案 / 悠泊医院门口举牌
- **MVP 三必备**:反馈渠道 / 官方公告 / 自动升级

## 📣 三、获取用户 Acquisition(第3章)

- **种子用户**
  - 少而精,定调性:Facebook 名校 / 知乎邀请制 / B站 100 题 / 小米 100 个梦想赞助商
  - 得女性者得天下
  - 提防"产品蝗虫"(同行、围观客、乱提意见)
- **笨办法**:聚美男扮女装写软文 / Airbnb 上门拍照(周营收 200→400 美元)
- **社交红利**:Zynga 霸榜 Facebook / Spotify 强制 FB 登录一周 +100 万 / 啪啪社交登录回流
- **数据抓取**:网易一键搬家 / 追 TA 抓头像(借鸡下蛋)
- **内容营销**
  - 三作用:引流量 / 养用户(7 次接触定律)/ 促转化
  - Upworthy 一文写 25 个标题做 A/B 测试
  - 长文更易传播(2000 词起步)
- **SEO / ASO**
  - Facebook 加站点地图,自然流量 ×100
  - Twitter 提交热门标签,站外访问 750 万→7500 万
  - 大姨吗副标题堆词 / Circa 只请满意者评分(89.5% 五星)
- **排队造势**:Mailbox 80 万人排队 / Robinhood 邀请插队 40 万名 / Trak.io 付 29 美元插队(转化 11%)
- **小挂件**:YouTube 允许嵌入 MySpace / Gleam 挂件文案测试(3.88%→17.16%)
- **文案心法**:休格曼滑梯理论,标题为了第一句,第一句为了第二句
- **地推**:携程机场蹲点 / 校内网注册送鸡腿 / Tinder 渗透校园派对圈
- **海外扩张**:猎豹 Clean Master 盯"清理"关键词,1.4 亿月活

## ⚡ 四、激发活跃 Activation(第4章)

- **LinkedIn 激活术**
  - 魔法数字 4:默认邀请 4 个好友转化最高
  - 双重病毒循环:新用户带新用户,老用户被召回
  - 声誉系统:活跃者替沉默者贴技能标签,借力打力
- **A/B 测试**
  - 三要素:两方案 / 只改一个变量 / 数据判定
  - Airbnb 星形改爱心 +30% / 奥巴马全家福胜过视频 +40.6%
  - HubSpot 加女性照片反而 −24%(不测不知道)
  - 谷歌 12000 次测试只有 10% 有效:要测,别迷信
  - OkDork 实战 3%→8%:删导航、放大输入框(别让用户思考)
- **诱饵效应**:多一个"不喜欢"按钮,喜欢点击 7000→12000;早点摊"加一个蛋还是两个"
- **降低门槛(绕路思维)**
  - Skype 伪立体声 / QQ 音乐假封面显示锁屏歌词 / Wi-Fi 钥匙截图 + OCR
- **补贴阶梯**:直接返利 → 限期券(卡流失周期)→ 打车现金战 → 红包(能传播,最大红包给新客)
- **游戏化**
  - 四特征:目标 / 规则 / 反馈 / 自愿参与
  - 星巴克星成就 / Foursquare 签到地主 / 滴滴滴米(难单奖励)
  - 警钟:只能锦上添花,Foursquare 因过度游戏化由盛转衰
- **机器人运营**:Reddit / Quora 自问自答撑场子 / 豌豆荚贴吧神兽 5 天传 2 万吧

## 💗 五、提高留存 Retention(第5章)

- **游泳池定律**:真增长 = 进水 − 漏水
- **为什么重要**:留存 +5% = 利润 +30%;卖老客是卖新客的 3 倍
- **流失五因**:程序漏洞(Color)/ 骚扰(微博)/ 新鲜感过(你画我猜)/ 有替代品(eBay 败给淘宝)/ 其他
- **留存基准**:游戏 40-20-10(次日/7日/30日);社交首月 80%;电商 20%~30%
- **性能就是留存**
  - 亚马逊:慢 100ms = 年损 100 万美元
  - Facebook 去非洲:启动 −50%、WebP 省 35% 流量、包体 −65%
  - Instagram 扁平化:资源 29→8 个,快 120ms
- **有损服务**:保核心舍枝节
  - QQ 农场高峰返回静态列表 / 微信放弃极端时消息顺序 / 小米"仅剩 5 万部"模糊数 / 刀塔传奇低清更新包
- **新手引导**:别让人面对空房间
  - Twitter:注册即关注 5~10 人更留人
  - Pinterest:替新手预填优质内容
- **社交维系与解绑**
  - 维系:飞机大战"合体"召回 / Facebook 注销页显示好友照片"他们会想你"(−7% 流失)
  - 解绑:Same 砍掉关注关系,次日留存 50%+(孤独的人需要没人盯着的地方)
- **唤醒机制**
  - EDM 四类:给奖励 / 报进展 / 个性化推荐 / 社交提示("有人圈了你"转化 75%)
  - 推送:开启者 62% 回流 vs 关闭者 32%;但 23% 因骚扰卸载
  - 网页唤起 App(Deep Link)

## 💰 六、增加收入 Revenue(第6章)

- **底层逻辑**(亚当·斯密):别指望善意,让人觉得有利可图
- **免费为什么成立**:边际成本趋零 / 海量用户摊薄 / 一分钱效应 / 国内土壤
- **免费五条变现路**
  - Freemium:QQ 会员 / Evernote(10 亿用户出 100 万付费)
  - 交叉补贴:吉列刀架刀头 / 游戏免费道具收费 / Dropbox 照片 App 耗光空间
  - 三方市场:Google 九成收入是广告 / 搜狗三级火箭
  - 开源变现:RootTools 捐赠+定制+卖文档
  - 上市或被收购(别当救命稻草)
- **免费的反面:Bidsketch 砍掉免费,转化 ×8~10**
- **重定向广告**:cookie 追踪,30 天见 7~10 次转化 ×3
  - Diapers 在 Facebook 嵌"我的清单",老客复购,营收 +30%
- **社交购物**:Wet Seal"和友人逛街"+10% / Etsy 猜好友喜好送礼
- **游戏化卖货**:罗辑思维微信卖月饼,多人代付+随机抢,13 天 4 万盒
- **变惩为奖(堵不如疏)**
  - QQ 会员 1 元点灯 300 万人:不封杀,红毛企鹅卖萌+八折,15% 转正
  - CleanMyMac 盗版失效给 5 折,化敌为友
  - 三原则:不责备 / 给补偿 / 便转化
- **商业智能**:百姓网 RAIDER,28 个 KPI 管电销,月业绩 +65 万

## 🦠 七、病毒传播 Referral(第7章)

- **两个关键数**
  - K 因子 = 感染率 × 转化率,>1 才能自我裂变
  - 循环周期越短越猛(视频分享几分钟一轮)
- **引爆三法则**(《引爆点》):个别人物 / 附着力的被记住
- **Bug 营销**:百度云"Bug"千分之一价,数天后宣布 7000 万用户 / 迅雷 1 分钱年卡认账
- **借势营销**:淘宝"去啊"文案大战 / 猎豹春运抢票版上新闻联播 / SF 光棍节程序员闯关(UV 2 万→16 万)
- **体外病毒循环**:追 TA 整蛊游戏一周 200 万人 / 知乎财务包子铺卖书登顶
  - 三考验:创意源源不断 / 生命周期短(换汤不换药)/ 与产品契合
- **内置传播因子**:AirDroid 分享解锁 / 美图动态测试入口 / 百度魔图 PK 大咖(免费榜 10 天第一)
- **8 大人性开关**(背下来直接用)
  - 喜爱(版权游戏转化 ×2.4)
  - 逐利(Paypal 注册送 10 美元,日增 7%)
  - 互惠(Dropbox 双方各得 250MB)
  - 求助(糖果传奇没体力找朋友)
  - 炫耀(支付宝年度账单)
  - 稀缺(Gmail 邀请 / Dribbble 码炒到 2000 元)
  - 怕错过(EverMemo 扫码解锁,标价 0.99 美元当锚)
  - 懒惰(一键分享,门槛每降一点传播多一截)
- **邮件助推**:SpringSled 排队+拉 5 人,进度邮件提醒,4 周 15 万用户
- **云诺末日策划(全招数实战)**
  - 免费送"无限"空间(99.94% 用户用不到 7GB,成本是纸面数字)
  - 手动点击领取:仪式感+控制成本+哒哒声引来围观
  - 故意留漏洞让技术宅"作弊"传播
  - 复盘六条:一句话说得清 / 参与超简单 / 成就时刻促分享 / 多留槽点 / 故意留漏洞 / 备好二次三次传播

## 🏆 八、完整案例集(第8章)

- **Airbnb**:卖麦片求生 → 机器人蹭 Craigslist → 上门拍照订房 ×2~3 → FB 建信任 → 星改心 +30% → "送好友 25 美元"胜过"你得 25 美元"

- **Github**:Fork+Pull Request 简化协作 / 用的人越多越好用(网络效应)/ 公开免费私密收费 / 猎头拿主页当简历
- **美丽说**:500 元/月请 QQ 群主带人 / 蔷薇粉拒绝男性 / 用户四层(达人 300+超级 5%+活跃+需求群众)/ 微博小测试滚雪球 / 臆想功能果断砍
- **外卖库**:SEO 流量 20%→60% / 监控微博人工真诚回复 / 陈奕迅字幕组蹭热点 / 兔子外卖袋转发 2 万 / 星探+免费午餐公益 / ASO 冲榜

## ⚖️ 九、职业道德与指标(后记+附录)

- **反面教材**:疯狂来往偷传玩家视频(3.6 万条)
- **三条底线**
  - 换位思考:己所不欲勿施于人
  - 隐私保护:最小授权,最大知情
  - 国际视野:做百年老店,不赚快钱
- **必背指标**
  - 流量:PV / UV / 跳出率 / 访问来源
  - 活跃:DAU / MAU / 使用间隔
  - 留存:次日 / 7 日 / 30 日留存率
  - 传播:K 因子(>1 自裂变)
  - 钱:ARPU(全摊)/ ARPPU(只算付费)/ LTV(一辈子贡献)> 获客成本才健康

## 🧠 全书一图流(极简记忆版)

```
先做对(PMF·MVP)
   ↓
拉进来(A:种子·渠道·SEO)
   ↓
用起来(A:A/B·降门槛·游戏化)
   ↓
留下来(R:性能·有损·唤醒)
   ↓
赚到钱(R:免费变现·变惩为奖)
   ↓
传出去(R:K因子·人性开关)
   ↓
守底线(信任是增长的地基)
```

> 一句话背下全书:数据代替猜,试验代替吵,巧劲代替砸钱;方法会过时,思维和底线不会。
