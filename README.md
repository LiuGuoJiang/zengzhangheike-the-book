## 关于本书

「增长黑客」（Growth Hacker）这一概念起源于硅谷，指的是一群以数据驱动营销、以市场指导产品、通过技术手段贯彻增长目标的人。他们既懂技术，又懂用户心理，擅长用低成本甚至零成本的手段，为初创公司实现用户与收入的爆发式增长。

本书是国内最早系统介绍「增长黑客」方法论的著作之一。全书围绕创业公司增长的核心命题展开，涵盖：

- **增长黑客的崛起**：这一角色的由来、职责、特质与常用工具箱
- **创造正确的产品**：用 PMF（产品-市场契合）和 MVP（最小化可行产品）验证需求，拒绝昂贵的失败
- **获取用户**：种子用户筛选、内容营销、SEO/ASO、社交红利、数据抓取等获客手段
- **激发活跃**：A/B 测试、降低活跃门槛、游戏化与自动化运营
- **提高留存**：优化性能、新手引导、社交维系与唤醒机制
- **增加收入**：免费模式、重定向广告、商业智能系统
- **病毒传播**：病毒循环的构建、用户心理把握与传播效率优化
- **完整案例集**：Airbnb、Tinder、GitHub、美丽说等国内外公司的增长实战复盘

书末附有增长黑客应当关注的常用指标、国外优秀增长黑客名单，以及对这一职业操守的思考。

## 为什么免费开放

这本书写于 2015 年。十年过去，书中的许多案例已经带上了时代的印记，但其底层的方法论——用数据说话、用实验验证、用产品本身驱动增长——在今天依然成立，甚至被越来越多的团队奉为常识。

与其让它躺在书架上积灰，不如把它放到阳光下。我把全书内容免费公开在这里，希望它能继续帮到正在创业路上摸索的人、对增长感兴趣的产品和运营同学，以及任何想把「增长」这件事想得更清楚一点的读者。知识的价值在于流动，而不在于囤积。
